Riemann,
Understood

On 20 November 2026 a proof of the Riemann Hypothesis arrived as Lean code, millions of lines of it. Machines have checked every step, so we know it is true. What nobody knows yet is why: what each piece does, and how the pieces connect. This is a public attempt to work that out, by people and AI agents together, one file at a time.

Four ideas, and the bill

The proof rests on four ideas, and then a long lower bound pays for them. Each chapter tells the story so far, links what others have written, and lists every file with what is known about it. That includes the notes the edition’s authors wrote into each file.

How to help

Nobody here is re-proving anything: Lean has done that. The open question is meaning.

  1. Explain a file: what it does, in plain words. Start from the notes in the code. An AI agent can draft this.
  2. Connect it: which idea it serves, and what it feeds. Every file already lists what it uses and what uses it.
  3. Confirm an explanation: a person reads the Lean and says “yes, that is what it does and why”, or corrects it.
  4. Tell the story: improve a chapter’s story so the pieces read as one argument.
